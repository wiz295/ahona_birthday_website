# Ahona's Birthday Website ♡

A responsive romantic birthday surprise built with HTML, CSS and vanilla JavaScript.

## Run it
1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Open `index.html` in a browser.
3. Replace the sample photo files in `images/` with your own photos. Keep the filenames:
   - `photo-1.jpg` through `photo-6.jpg`
   - Or change the image paths in `index.html`.
4. Add a romantic MP3 file at `assets/our-song.mp3`. The music button starts playback only after the visitor taps it (browser autoplay rules).

## Personalize it
- Edit the timeline headings, dates, and paragraphs in `index.html`.
- Edit the letter text in the `letter-paper` section in `index.html`.
- Change captions below each photo in `index.html`.
- Adjust colours and typography in `style.css`.

## Publish it free
You can upload the folder to GitHub Pages, Netlify, or Cloudflare Pages. Upload the whole folder (including `images` and `assets`) so the photos and music paths work.

## Photo tips
Use 5–8 portrait or square photos for the best layout. For privacy, share the published link only with the people you choose.
